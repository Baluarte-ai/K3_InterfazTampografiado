# K3_InterfazTampografiado

Interfaz HMI industrial táctil para estación de tampografiado KOSTAL.

## Características
- **Control de Movimiento y Ciclo:** Inicio, Paro, Reset, Home, Ir a Cero, Avanzar Pieza, modo Manual, Jog en cruz (límites 0 a 200 mm).
- **Matriz de Piezas:** Visualización dinámica de la cuadrícula de producción y seguimiento de piezas.
- **Comunicación OPC UA:** Conexión con PLC WAGO PFC200 y modo de simulación integrado en caso de operar fuera de línea.
- **Gestión de Recetas/Programas:** Creación y configuración de recetas con dimensiones, offsets e imágenes de jigs.
- **Estadísticas y Reportes:** Exportación de métricas de producción a Excel y CSV.
- **Gestión de Usuarios y Seguridad:** Roles (Operador / Administrador) y tutorial interactivo guiado para nuevos operadores.
